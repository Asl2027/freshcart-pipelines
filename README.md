
# FreshCart Data Engineering Pipeline

## Project Overview
This project demonstrates an end-to-end data engineering pipeline for FreshCart.

It covers:
- Git and GitHub version control
- CI/CD using GitHub Actions
- ELT pipeline implementation using Snowflake
- Data quality checks and validation
- Machine learning pipeline using Mage
- Event-driven messaging using RabbitMQ

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Pytest
- Snowflake
- Mage
- RabbitMQ
- GitHub Actions
