
# Git Commands Used in FreshCart Project

| Git Command | Purpose |
|---|---|
| git init | Initializes a new Git repository |
| git clone | Copies a remote repository to the local machine |
| git status | Displays the current state of the working directory |
| git add . | Stages all modified and new files |
| git commit -m "message" | Saves staged changes with a commit message |
| git push origin main | Pushes local commits to the remote main branch |
| git pull origin main | Fetches and merges changes from the remote main branch |
| git log | Displays the commit history |
| git branch | Lists existing branches |
| git checkout -b feature | Creates and switches to a new branch |
